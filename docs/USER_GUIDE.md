# User guide

> **Status:** Phase 0. Accounts, face enrollment and attendance arrive in later phases; this guide
> grows with each one.

## Getting around

| On a phone                                       | On a computer                   |
| ------------------------------------------------ | ------------------------------- |
| Use the **bottom bar** to move between pages     | Use the **sidebar** on the left |
| Top bar: language, theme, notifications, profile | Same top bar                    |

## Change the language

1. Tap the **language** icon (文A) in the top bar.
2. Choose **English** or **हिन्दी**.

You stay on the same page; only the language changes. The choice is remembered on this device, and
the address shows it (`/en/…` or `/hi/…`), so a link you share opens in the same language.

## Change the theme

1. Tap the **sun/moon** icon in the top bar.
2. Choose **Light**, **Dark** or **System** (follows your device setting; this is the default).

## Notifications

The **bell** opens your notifications. There are none yet: attendance, request and ticket alerts
start arriving in later phases.

## Accessibility

- Press **Tab** on a page to reveal **Skip to content**.
- Animations are reduced automatically if your device has "reduce motion" turned on.
