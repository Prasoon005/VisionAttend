# Troubleshooting

| Symptom                                                                                   | Cause                                                                                             | Fix                                                                                                                                                             |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm install` or `next build` is very slow, or fails with `EPERM`/`EBUSY`                 | The repository is inside OneDrive and files are being synced or locked                            | Move the repository outside OneDrive (e.g. `C:\dev\VisionAttend`), or pause OneDrive syncing                                                                    |
| Vitest fails to start: `Cannot read properties of undefined (reading 'bind')` in `undici` | `jsdom` ≥ 30 needs Node ≥ 22.22                                                                   | Keep `jsdom` at 28.1.0 ([ADR-007](DECISIONS.md#adr-007--toolchain-pinned-to-node-2212-compatibility)) or upgrade Node                                           |
| `npm run lint`: "typescript-eslint does not support TS 7.0"                               | TypeScript 7 was installed                                                                        | Keep TypeScript on 6.0.x ([ADR-005](DECISIONS.md#adr-005--typescript-60-not-70))                                                                                |
| `tsc` errors: `Cannot find name 'PageProps'` / `'LayoutProps'`                            | Next's route types were not generated yet                                                         | Use `npm run typecheck` (runs `next typegen` first), or run `npm run dev`/`build` once                                                                          |
| Playwright: "Executable doesn't exist"                                                    | Browsers not installed                                                                            | `npx playwright install chromium webkit`                                                                                                                        |
| E2E reuses an old server on port 3100                                                     | Locally, Playwright reuses a running server                                                       | Stop the old `next start` process, then rerun                                                                                                                   |
| `npm audit` shows 5 high vulnerabilities                                                  | Dev-only `braces` advisory via `eslint-config-next`                                               | Expected, see [ADR-010](DECISIONS.md#adr-010--accept-a-dev-only-braces-advisory). `npm audit --omit=dev` is clean                                               |
| Pre-commit hook doesn't run                                                               | Husky not enabled for this clone                                                                  | Run `npx husky` once                                                                                                                                            |
| `npm run test:db`: "Local Supabase is not running"                                        | Docker stack is stopped                                                                           | Start Docker Desktop, then `npx supabase start`                                                                                                                 |
| Sign-in fails with "Email logins are disabled"                                            | `[auth.email] enable_signup = false` in `supabase/config.toml` turns off the whole email provider | Keep it `true`. Public sign-up is blocked by `[auth] enable_signup = false` and the invite-only trigger. Restart: `npx supabase stop` then `npx supabase start` |
| "Database error creating new user"                                                        | The invite-only trigger rejected the sign-up (missing, expired or used-up invite)                 | Expected without a valid invite. `docker logs supabase_auth_visionattend` shows the exact reason                                                                |
| Demo accounts missing, or tests say "Seeded super admin missing"                          | The database was created without the seed                                                         | `npx supabase db reset`                                                                                                                                         |
